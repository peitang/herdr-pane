# 驗收清單

> **狀態：第一版已實作。** 勾選代表已由自動測試或本機受控檢查覆蓋；不表示所有環境均驗證。隔離原生行為與待驗證限制見 [驗證紀錄](document-review.md)。

## 列出與選取

- [x] 只有本機時，能列出 agent 並顯示新增遠端提示。
- [x] 本機與多個已啟用遠端的 agent 可整合到同一份清單。
- [x] 不查詢被停用的 profile；同主機不同 session 的 profile 可區分。
- [x] 一個來源離線、逾時或回傳異常資料，不會阻止其他來源顯示。
- [x] 本機 server 未啟動時仍能列遠端，一般查詢不自動啟動本機 server。
- [x] 查詢期間編號選取未開放；清單固定後編號才可使用。
- [x] 空清單、空白取消、非數字與超出範圍的輸入都有清楚結果。
- [x] 同名 agent、重複 pane 編號與空白名稱不會導致跨主機誤連。
- [x] 純 shell 不列入預設 agent 清單；未知狀態不被當成 idle。
- [ ] 正確處理自己的 pane；繼承的環境識別字與實際 pane 不符時，不依其他 client 焦點猜測。

## 接上與離開

- [ ] 本機與遠端都能接上選取的原終端，沒有意外建立另一個 agent。
- [x] 查詢與 attach 使用相同 profile、SSH 目標及 session。
- [x] terminal 識別碼已更換、agent 已結束或目標無法驗證時，重新列出，不誤連。
- [x] 包含空白或特殊字元的顯示資料不會成為 shell 指令。
- [ ] 遠端非互動 shell 找不到 Herdr 時，有明確診斷結果。
- [x] direct attach 被占用時不自動 takeover。
- [ ] 被其他人接管時停止本次連線，不自動搶回操作權。
- [ ] 接上時的 pane 尺寸變化與共享畫面重排經實測。
- [ ] 正常 detach 不觸發重連，也不停止 agent／server。
- [ ] 巢狀 Herdr 的前綴鍵與 detach 說明經實測。
- [ ] 多 client 同時查看或輸入時的實際行為有紀錄，不宣稱存在全域輸入鎖。

## 新增遠端

- [x] `--add-remote` 無參數時會詢問；帶入 SSH 目標時不重複詢問。
- [x] 接受已支援的 SSH 別名與目標格式，拒絕控制字元與指令注入輸入。
- [ ] 原生 SSH 驗證、MFA 與主機金鑰確認未被跳過。
- [ ] 原生安裝、更新與替換 server 的問題不被自動回答。
- [x] 已說明新增遠端可能啟動背景 server；依版本選擇或明確指定 session。
- [ ] 取消與失敗不留下自製的假成功 profile，也不影響其他連線。
- [ ] session 與標籤的選取結果和 Herdr 儲存內容一致。
- [x] 成功後重新讀取 profile 並回到 agent 選單。
- [x] 設定完成但沒有 agent 時顯示空清單，不誤判為設定失敗。

## 異常與相容

- [x] 暫時網路中斷回到選單，手動重連會重新核對目標與占用狀態。
- [x] 驗證與 host-key 問題提示修正方向；不能只以結束碼 `255` 分類。
- [ ] 查詢或等待時 Ctrl+C 能取消；取消不停止遠端工作。
- [ ] 需要登入使用者環境的功能，在 SSH 登出後仍能按預期運作。
- [x] 只保留正式入口，不建立舊名稱。
- [ ] 實際支援的作業系統、Herdr client／server 組合已逐一紀錄。

自動重連列為後續候選，須先測得舊連線的擁有權釋放方式、接管結果與錯誤分類，再決定是否納入；不能以本清單視為已承諾支援。

## 發布條件

- [x] 文件中的已實作／待實作狀態與實際檔案一致。
- [ ] 文件、圖表、Git 內容與作者資料完成機敏資料覆核。
- [ ] staging 或受控測試環境驗證完成，並附結果；無法執行時明確標示。
- [ ] 只推送功能分支，由維護者依既有 review 流程合併。
